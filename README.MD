# Ruta Motor | Concesionaria de autos

Landing page académica para una concesionaria multimarca. Presenta vehículos destacados, marcas, características, ventajas de compra y contacto para consultas o pruebas de manejo.

## Tecnologías
- HTML5 semántico
- CSS3 embebido (Grid, Flexbox y media queries)

## Cómo visualizarlo
Abre `index.html` directamente en un navegador. Las fotografías y tipografías se cargan desde servicios externos, por lo que requieren conexión a Internet.
