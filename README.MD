# 🚗 Ruta Motor | Concesionaria de autos

![Ruta Motor Banner](https://images.unsplash.com/photo-1552519507-da3b142c6e3d?q=80&w=1200&auto=format&fit=crop)

> Landing page académica interactiva para una concesionaria de vehículos multimarca. Presenta modelos destacados, catálogo de marcas, características clave, ventajas competitivas y un formulario de contacto para pruebas de manejo.
